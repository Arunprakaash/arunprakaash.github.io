03 — The Switch That Isn't Really a Switch

Why neural nets need activation functions — and how sigmoid, tanh, ReLU, and softmax each solve the linearity problem in their own way.

The perceptron used a step function — on or off, 1 or 0, no in-between. That was fine for flipping a single neuron but terrible for learning, because you can’t take a gradient of a vertical wall.

The entire deep learning revolution rests on one quiet fix: replace the hard step with something smooth.

The Linearity Problem #

Imagine stacking two perceptron layers with no activation function. Layer 1 computes $\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1$. Layer 2 computes $\mathbf{W}_2 (\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2$.

Expand that:

$$\mathbf{W}_2 \mathbf{W}_1 \mathbf{x} + \mathbf{W}_2 \mathbf{b}_1 + \mathbf{b}_2$$

That’s just $\mathbf{W}’ \mathbf{x} + \mathbf{b}’$ — a single linear transformation. No matter how many layers you stack, without nonlinearity they collapse into one. A 100-layer network with no activations is equivalent to logistic regression.

Activation functions are how depth becomes power. They inject the nonlinearity that lets each layer learn something genuinely new.

The Step Function (and Why We Left It Behind) #

The original perceptron used:

$$f(z) = \begin{cases} 1 & \text{if } z \geq 0 \ 0 & \text{if } z < 0 \end{cases}$$

It’s a hard threshold. The derivative is zero everywhere except at $z = 0$ where it’s undefined. That means gradient descent has nothing to work with — the loss surface is flat in every direction.

We need something with a slope.

Sigmoid — The Smooth Step #

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Sigmoid takes any real number and squashes it into $(0, 1)$. At $z = 0$ you get exactly $0.5$. As $z \to +\infty$ you approach 1; as $z \to -\infty$ you approach 0.

Its derivative is beautifully self-referential:

$$\sigma’(z) = \sigma(z)(1 - \sigma(z))$$

If the output is $0.7$, the gradient is $0.7 \times 0.3 = 0.21$. You never need to compute anything expensive — the forward pass gives you everything.

The catch: sigmoid saturates. When $z$ is very large or very small, $\sigma’(z) \approx 0$. Gradients passing through saturated neurons become vanishingly small — the vanishing gradient problem. In deep networks, multiplying many near-zero gradients together means the early layers learn almost nothing.

Also, sigmoid outputs are always positive (range $(0,1)$), which means the gradient updates always have the same sign — causing a zig-zagging inefficiency called gradient zig-zagging.

Tanh — Centered Sigmoid #

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$$

Tanh is sigmoid’s better-adjusted sibling. It outputs $(-1, 1)$ and is centered at zero — so gradients can be positive or negative, which helps with the zig-zagging problem.

It’s related to sigmoid by:

$$\tanh(z) = 2\sigma(2z) - 1$$

Its derivative:

$$\tanh’(z) = 1 - \tanh^2(z)$$

Still saturates, still has vanishing gradients in deep networks — but preferred over sigmoid for hidden layers when you want zero-centered outputs.

ReLU — The Accidental King #

$$\text{ReLU}(z) = \max(0, z)$$

That’s it. No exponentials. No fractions. Just: if negative, zero; if positive, keep it.

Introduced for neural networks in 2010 and it quietly changed everything. Why does something so simple work?

Sparse activations. On average half the neurons output zero — the network becomes sparse, which is computationally efficient and empirically generalises better.

No saturation on the positive side. If $z > 0$, the gradient is exactly 1. It passes through perfectly. Deep networks finally started training properly.

Cheap. A single comparison operation. GPUs can do billions of these.

The derivative:

$$\text{ReLU}’(z) = \begin{cases} 1 & \text{if } z > 0 \ 0 & \text{if } z \leq 0 \end{cases}$$

The dying ReLU problem. If a neuron consistently receives negative inputs, it outputs zero, gets zero gradient, and never recovers. It’s “dead” — it stopped contributing to the network.

Fixes include:

  • Leaky ReLU: $f(z) = \max(0.01z, z)$ — lets a tiny gradient flow when negative
  • ELU, GELU, Swish — smoother variants used in modern transformers

Despite its flaws, vanilla ReLU is still the default for most hidden layers. If it ain’t broke…

Softmax — From Scores to Probabilities #

For classification problems, the final layer often needs to output a probability distribution — values between 0 and 1 that sum to 1. That’s softmax.

Given a vector of scores $\mathbf{z} = [z_1, z_2, \ldots, z_k]$:

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{k} e^{z_j}}$$

The exponentials make larger scores dominate (winner-take-most), and dividing by the sum normalises to a proper probability distribution.

For a 3-class problem with scores $[2.0, 1.0, 0.1]$:

$$e^{2.0} = 7.39, \quad e^{1.0} = 2.72, \quad e^{0.1} = 1.11$$ $$\text{sum} = 11.22$$ $$\text{softmax} = [0.659, 0.242, 0.099]$$

The model is 66% confident it’s class 1. Softmax is almost always paired with cross-entropy loss, which has a clean gradient and is the standard recipe for classification.

Side-by-Side Comparison #

Function Range Zero-centred Saturates Typical use
Step ${0, 1}$ No Yes (hard) Perceptron only
Sigmoid $(0, 1)$ No Yes Binary output layer
Tanh $(-1, 1)$ Yes Yes RNNs, hidden layers
ReLU $[0, \infty)$ No No (positive side) Hidden layers (default)
Leaky ReLU $(-\infty, \infty)$ No No When dying ReLU is a problem
Softmax $(0, 1)$, sums to 1 No — Multi-class output layer

The Intuition #

Think of activation functions as editorial judgment. The linear part ($\mathbf{Wx} + \mathbf{b}$) gathers evidence. The activation function decides what to do with it:

  • Step: binary verdict, no nuance
  • Sigmoid: nuanced verdict scaled to a confidence between 0 and 1
  • Tanh: same, but centred so it can push in either direction
  • ReLU: pass the evidence through unchanged if it’s positive, silence it if it’s negative
  • Softmax: distribute confidence across all possible verdicts

The right choice depends on where in the network you are and what you’re trying to do. For hidden layers today: ReLU (or a variant) is the default. For binary classification output: sigmoid. For multi-class output: softmax.
